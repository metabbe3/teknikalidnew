## 3 Paling Berbahaya

1. **[HIGH] cache-or-recompute race di swing route** — setiap request setelah TTL memicu query DB berat 2× penuh secara paralel; semua 500 karena throw sebelum menulis cache, cache tetap kosong selamanya (`cacheExpiresAt` tak pernah diperbarui saat error), dan GET yang diimpor langsung oleh halaman `/swing` ikut crash per-request.
2. **[HIGH] `Math.max(1, …)` fabrikasi stop-loss** — saham < Rp150 dengan ATR < Rp0.17: `estimatedStop` dipaksa ≥ 1, `actualRisk` bisa ≤ 0 → RR hard-coded "2.0" palsu. Telah tervalidasi matematika (close=100, atr=0.3 → stop=100=entry, risk=0).
3. **[HIGH] `lastNWeeks` off-by-one hari Minggu** — sitemap melewatkan minggu paling baru yang SUDAH selesai. Live: minggu-2026-10-26 (200, konten lengkap) tidak ada di sitemap; Google melihat halaman ber-`lastModified` 7 hari lebih tua dari kenyataan.
