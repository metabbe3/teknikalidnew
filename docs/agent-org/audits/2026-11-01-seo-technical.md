# Technical SEO Audit — teknikal.id

**Tanggal:** 2026-11-01 · **Metode:** live crawl (curl, 20+ URL) + inspeksi repo `~/Documents/teknikalidnew`
**Konteks:** GSC ~875 impresi/hari, 5 klik/hari, posisi rata-rata 66–68. Target: naikkan traffic organik.

**Ringkasan sehat:** Semua halaman sampel punya H1 tunggal, canonical benar, robots meta benar, next/image konsisten, 0 script pihak ketiga, trailing-slash & www redirect bekerja, JSON-LD (Organization/WebSite/FAQ/Breadcrumb) ada di halaman kunci. Masalahnya bukan hygiene dasar — tapi **arsitektur URL programmatic yang salah arah, orphan pada halaman uang, dan sinyal situs berita yang setengah jadi**.

## Data pendukung

- **Sitemap**: 1.375 URL — /stocks/* 616, /saham/*/kenapa-naik 575, /berita 69, /akademi 67, sektor 12, laporan-pasar 9, indeks 7, hub ~20. Semua ber-lastmod (format ISO benar).
- **Halaman kunci TIDAK ada di sitemap** (sudah benar karena semuanya redirect by-design): /pasar, /swing, /harga-saham-hari-ini, /track-record, /bottom-fishing, /screener → **tapi /swing dan /bottom-fishing adalah halaman indexable "index, follow" yang TIDAK ada di sitemap** — sitemap wajib ⊇ halaman indexable. Tambahkan keduanya (dan /pasar, /track-record jika noindex disengaja, biarkan).
- **Redirect**: http→https 301 ✓, www→apex 308 ✓ (2-hop dari http://www), trailing-slash 308 konsisten ✓.
- **robots.txt**: block /api/ /auth/ /admin/ /paper-trading/ /portfolio/ /watchlist /billing /settings /payment — selain isu /paper-trading di atas, bersih.
- **Structured data**: Organization+WebSite+SearchAction global ✓; FAQPage di /stocks, /saham-oversold, /kalender-dividen, /aliran-dana-asing, /stocks/BBCA.JK ✓; BreadcrumbList luas ✓; Dataset di kalender/aliran ✓; **Article hanya di kenapa-naik, TIDAK di /berita/[slug]** ✗.
- **Cannibalization check**: /screener dan /harga-saham-hari-ini sudah di-308 ke /stocks (baik); tidak ada duplikat indexable — sisa isu hanya mismatch H1 /stocks.
- **Konten tipis**: kenapa-naik ±500–530 kata per halaman × 575 — programmatic terbesar dan paling rapuh.

## Prioritas eksekusi (impact terhadap KPI traffic)

1. Beri internal link + Article schema ke berita (asets konten paling siap ranking — artikel ±1.500 kata).
2. Hub uang keluar dari orphan (kalender-dividen, aliran-dana-asing) via nav + konteks artikel.
3. Perbaiki/segmentasi programmatic kenapa-naik (bebaskan crawl budget 575 URL → /stocks).
4. Title hygiene (dobel brand, H1 /stocks).
5. Arsip berita + FAQ tanya pagination.
