# Security Audit — teknikal.id (statis + pasif)

**Tanggal:** 2026-11-02 (audit dijalankan 1 Nov malam WIB)
**Scope:** src/app/api/** authZ, SQL injection, secrets, headers, rate limit, mass assignment, IDOR, admin middleware, dependency, docker.
**Metode:** statis (grep + baca kode) + pasif (git history, `docker exec ... psql SELECT`, verifikasi hash tanpa mencetak nilai secret, cek reachabilitas repo publik). Tidak ada exploit aktif, tidak ada write DB, tidak ada load test.
**Catatan env var:** nilai secret TIDAK ditulis di laporan ini — hanya nama env var + status.

## Ringkasan

| Severity | Count |
|---|---|
| CRITICAL | 0 |
| HIGH | 3 |
| MED | 3 |
| LOW | 5 |

**Fix SEGERA (urutan):**
1. **H1** — CRON_SECRET lama hardcode di `scripts/cron-curl.sh` + `idx-sync.plist`, ter-commit & ter-fetch publik dari GitHub (repo `metabbe3/teknikalidnew` = **public**, diverifikasi via GitHub API `private:false` + raw file HTTP 200). Secret itu sudah TIDAK sama dengan live CRON_SECRET (diverifikasi md5, tanpa mencetak nilai), tapi riwayat git + repo publik tetap membocorkannya. Rotasi CRON_SECRET, purge history / private-kan repo, hapus literal dari script (baca dari env).
2. **H2** — `POST /api/ai/eval` tanpa auth: 1 request = hingga 4 panggilan LLM upstream (1 run + 3 judge) — unauthenticated cost-abuse di bawah global limit 120 req/min/IP. Gate dengan `requireAdmin()` (route ini internal QA owner 30 Okt).
3. **H3** — `follow-redirects` HIGH (npm audit, via `midtrans-client`→`axios`) — satu-satunya high; fix via npm `overrides` atau upgrade midtrans-client.

## Yang sudah BENAR (pola patut dipertahankan)

- **AuthZ per route:** 145 route file dipindai. Semua route mutasi data user memakai `requireAuth()`/`authService.requireAuth()` + scope `user.id`; admin API memakai `requireAdmin()` (grep -L: nol admin route tanpa auth). Route publik yang tersisa memang by-design (market data, waitlist dgn origin-check + limit 10/mnt + WA di-hash, feedback saham dedup ipHash 1/hari, engagement beacon limit 65/mnt).
- **Cron:** semua 11 route `/api/cron/*` pakai `requireCronSecret` (`src/lib/cron-guard.ts`) — fail-closed saat `CRON_SECRET` kosong + `timingSafeEqual`.
- **Injection:** `$queryRawUnsafe` hanya 4 lokasi (`stock.repository.ts` findVolumeSpikes/findHypeAlerts/findWeeklyWindowChanges/findWeeklyIndicatorSnapshots) — semuanya placeholder `$1..$4` + array params (parameterized, aman); sisanya tagged `$queryRaw`. Nol string-concat input user ke SQL. Tidak ada `Prisma.$executeRawUnsafe` di src/scripts.
- **Mass assignment:** tidak ada `...body` spread langsung ke prisma update. `PATCH /api/profile` allowlist `{name,bio,username,socialLinks}` + validasi (bio ≤200, username regex + uniqueness check, socialLinks whitelist platform). Portfolio PUT memetakan field eksplisit + `Number()` coercion.
- **IDOR:** paper-trading `cancelOrder`/`closePosition`/`updatePosition` cek `order.accountId !== account.id` → NotFound (no-oracle); portfolio/watchlist/thesis key by `user.id`+ticker. `/api/portfolio/public/[username]` hanya expose bila `portfolioPublic=true`.
- **Admin middleware:** `/admin/**` + `/api/admin/**` di-guard proxy.ts: session → verify role ADMIN dari DB (anti stale-JWT) → session timeout 4 jam (admin) / 7 hari (rememberMe). Unauth API dibalas 404 (anti-enumeration).
- **Secrets di git:** `.env` di `.gitignore` (`/.env/` + `.env*`); `.env` **tidak pernah** ter-commit (`git log --all --diff-filter=A -- .env*` → hanya `.env.example` di 51005a8, isinya placeholder). `.env` lokal permission 600. Tidak ada pattern API-key/token/password hardcoded di src/scripts (di luar 2 temuan CRON_SECRET di atas). App container: 4 secret env ter-set (AUTH_SECRET, CRON_SECRET, GOOGLE_CLIENT_SECRET, MIDTRANS_SERVER_KEY) — nama saja, nilai tidak diperiksa/dicetak.
- **Webhook pembayaran:** Midtrans notification verify `signature_key` (sha512 server-key) sebelum mutasi; userId/planId/duration datang dari custom_field yang ikut tersign.
- **Docker:** app `127.0.0.1:3000`, db `127.0.0.1:5433` — keduanya loopback-only (diverifikasi `docker port` + netstat; komentar audit 28 Okt konsisten). Cloudflare tunnel masuk via localhost — spoofing `cf-connecting-ip` dari luar tidak mungkin direct-origin.
- **Headers:** CSP + HSTS (2 th, preload, includeSubDomains) + X-Frame-Options DENY + Referrer-Policy + Permissions-Policy (camera/mic/geo off) di proxy.ts; duplikat HSTS/XFO di next.config.ts (redundan tapi tidak berbahaya). CSRF origin-check untuk semua POST/PUT/PATCH/DELETE `/api/*` (exempt: payment webhook tanda-tangan, auth callback, cron bearer).
- **Path traversal:** `/api/image-gen/serve/[filename]` pakai `path.basename` equality-check — aman.

## Verifikasi eksekusi (bukti, bukan asumsi)

- GitHub API `repos/metabbe3/teknikalidnew` → HTTP 200, `private:false`; `raw.githubusercontent.com/.../scripts/cron-curl.sh` → HTTP 200 (secret stale ter-expose publik).
- md5 compare di container: committed cron-curl.sh secret ≠ live app `CRON_SECRET`; plist secret ≠ live; live DB `POSTGRES_PASSWORD` ≠ default compose. (Nilai tidak pernah dicetak.)
- `npm audit --omit=dev`: 11 vuln (1 high follow-redirects, 8 moderate, 2 low; 0 critical).
- `docker exec ... psql -t -A`: 3 user ADMIN, 32 baris AiEvalRun (bukti /api/ai/eval aktif dipakai tanpa gate).
